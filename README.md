# 路由系統

##  專案架構

```
route/  (路由器專案根目錄)
├── Makefile             # 負責發號施令，調度各部門工作
├── bin/                 # 最終編譯好的執行檔 (my_dhcp, my_dns...) 都放這
│
├── common/              # 【零件倉庫】(工具庫)
│   ├── Makefile         # 負責把零件加工成半成品 (.o)
│   ├── include/         # 說明書 (.h) - 告訴別人怎麼用這些工具
│   └── src/             # 原料區 (.c) - 實作 Logger, Checksum 等通用功能
│
├── dhcp/                # DHCP模組
│   ├── Makefile         # 負責組裝 DHCP，並去倉庫拿零件來用
│   ├── include/         # DHCP 專用的規格書 (.h)
│   └── src/             # DHCP 的核心邏輯 (.c)
│
├── dns/                 # DNS模組(未來擴充)
└── nat/                 # NAT 模組(未來擴充)
```
- Hroute是一個基於 Linux 環境開發的輕量級路由系統框架。
- 本專案採用 C 語言編寫，旨在提供一個高效率、易於擴充的網路服務解決方案。透過模組化的架構設計，將不同的網路協議（如 DHCP, DNS, NAT）獨立開發與編譯，並共享底層通用工具庫，實現了高度的程式碼復用性與維護性。
## 架構設計介紹

- 模組化編譯架構：每個子目錄擁有獨立的 Makefile 與 include 環境，方便開發者獨立測試單一模組。

- 統一的二進位管理：編譯結果統一存放於 bin/ 目錄，簡化部署與安裝流程。

- 嚴謹的目錄規範：區分 src (實作) 與 include (規格定義)，確保 API 介面清晰，降低後續擴充的難度。

- DHCP 模組：動態主機配置協議實作，負責自動化 IP 位址分配與管理。

- DNS 模組：支援網域名稱解析服務。

- NAT 模組：實作網路位址轉換，提供內外網封包轉發功能。
